## About The Project

<div align="left">
  <a href="https://github.com/BacHaSoftware/employee_contract_manager">
    <img src="/bhs_employee_contract/static/description/banner.png" alt="Setting">
  </a>
</div>

#### Key Features:

🌟 <code>Streamlined Contract Access</code>: Access dedicated Employee Contracts and Trainee Contracts menus within the Employee module, providing a centralized view of all contracts. HR can quickly review contract information without opening individual employee profiles.

🌟 <code>Proactive Contract Monitoring</code>: Display the Days Left field together with key contract information, allowing HR to easily monitor contract validity, identify upcoming expirations, and plan renewals proactively.

🌟 <code>Flexible Contract Filtering</code>: Default to the Running Contracts filter when opening the contract list, while providing quick filters for Running Contracts, Expired Contracts, and Future Contracts to simplify daily contract management across all employees.
